# StockFlow — Operation Manual

> **Для кого:** Владелец магазина, кассир, кладовщик, бухгалтер
> **Версия:** 1.0.0-RC

---

## 1. Начало рабочего дня

### 1.1 Вход в систему

1. Откройте приложение StockFlow
2. Введите email и пароль
3. Нажмите **Login**

**Если забыли пароль:**
> ⚠️ В текущей версии нет функции восстановления пароля.
> **Обход:** Администратор может создать нового пользователя через админ-панель.
> Храните пароль в менеджере паролей.

### 1.2 Открытие кассовой смены

> **Роль:** Кассир

1. Главное меню → **Cash Shift** → **Open Shift**
2. Укажите:
   - **Склад:** Основной склад
   - **Начальный остаток:** Сумма наличных в кассе на начало дня
3. Нажмите **Open**

✅ Смена открыта. Все продажи в течение дня будут привязаны к этой смене.

---

## 2. Товары

### 2.1 Создание нового товара

> **Роль:** Менеджер / Кладовщик

1. Главное меню → **Products** → **+ Add Product**
2. Заполните поля:
   - **Название*** — обязательно
   - **SKU** — артикул (уникальный, проверяйте вручную)
   - **Штрихкод** — для сканера
   - **Цена продажи*** — обязательно
   - **Закупочная цена**
   - **Единица измерения** — шт, кг, л, и т.д.
   - **Категория** — для группировки в отчётах
   - **Бренд**
   - **Описание**
3. Нажмите **Save**

> ⚠️ **Важно:** Система не проверяет уникальность SKU. Контролируйте это вручную.

### 2.2 Поиск товара

1. Главное меню → **Products**
2. Используйте строку поиска: название, SKU или штрихкод
3. Для фильтрации по категории используйте выпадающий список

### 2.3 Редактирование товара

1. Найдите товар → нажмите на него
2. Измените нужные поля
3. Нажмите **Save**

## 3. Склад

### 3.1 Приём товара (Goods Receipt)

> **Роль:** Кладовщик
> **Когда:** Товар arrived от поставщика

#### Шаг 1: Создать Purchase Order
1. **Purchasing** → **+ New Purchase Order**
2. Выберите поставщика
3. Добавьте товары и их количество
4. Укажите цены, скидки, налоги
5. Нажмите **Save as Draft**

#### Шаг 2: Утвердить и заказать
1. Откройте созданный Purchase Order
2. **Submit** → статус меняется на Pending
3. **Approve** → статус меняется на Approved
4. **Order** → статус меняется на Ordered

#### Шаг 3: Принять товар
1. Откройте Purchase Order со статусом **Ordered**
2. Нажмите **Receive Goods**
3. Проверьте количество и цену
4. Нажмите **Confirm** — товар поступит на склад

✅ Статус PO изменится на **Received** (или **Partially Received**).
✅ Остатки товара на складе увеличатся.

### 3.2 Возврат поставщику

1. **Purchasing** → **Returns** → **+ New Return**
2. Выберите поставщика и Purchase Order
3. Укажите товары и количество
4. Нажмите **Save as Draft**
5. **Submit** → **Complete**

✅ Товар списывается со склада.

### 3.3 Перемещение между складами

1. **Inventory** → **Stock Transfer**
2. Укажите:
   - Товар
   - Откуда: склад-источник
   - Куда: склад-назначение
   - Количество
3. Нажмите **Transfer**

✅ Остатки на source складе уменьшатся, на destination — увеличатся.

### 3.4 Корректировка остатков

1. **Inventory** → **Stock Adjust**
2. Укажите:
   - Товар
   - Склад
   - Новое количество (положительное = приход, отрицательное = расход)
   - Причина (например: "Ошибка инвентаризации")
3. Нажмите **Adjust**

## 4. Продажи (POS)

### 4.1 Продажа товара

> **Роль:** Кассир

1. **Sales** → **+ New Sale**
2. Добавьте товары:
   - Сканируйте штрихкод или найдите товар
   - Укажите количество
3. Если нужно — примените скидку (на товар или на весь чек)
4. Выберите способ оплаты:
   - **Cash** — внесите сумму
   - **Card** — терминал
   - **QR** — Kaspi QR и т.д.
   - **Bank Transfer** — перевод
   - **Gift Card** / **Store Credit**
5. Можно комбинировать: часть наличными, часть картой
6. Нажмите **Complete Sale**

✅ Товар списывается со склада.
✅ Чек создаётся (статус DRAFT).
✅ Продажа привязывается к открытой кассовой смене.

### 4.2 Возврат товара

1. **Sales** → Найдите продажу → **Refund**
2. Подтвердите возврат

✅ Товар возвращается на склад.
✅ Статус продажи меняется на REFUNDED.

### 4.3 Отмена продажи

1. **Sales** → Найдите продажу → **Cancel**

> Отменить можно только DRAFT или PENDING продажу.
> COMPLETED продажу — только через Refund.

## 5. Кассовая смена

### 5.1 Внесение / Изъятие наличных

> **Роль:** Кассир

- **Cash In** — если нужно добавить наличные в кассу (например, принесли размен)
- **Cash Out** — если нужно изъять наличные (например, инкассация)

### 5.2 Закрытие смены

1. **Cash Shift** → **Close Shift**
2. Укажите **фактический остаток наличных** в кассе
3. Нажмите **Close**

Система покажет X-отчёт:
- Ожидаемый остаток (начальный + продажи + cash in - cash out)
- Фактический остаток
- Расхождение (если есть)

> Если расхождение > 0 — проверьте операции за смену.

### 5.3 Z-отчёт

После закрытия смены доступен **Z-Report** — финальный отчёт по закрытой смене для бухгалтерии.

## 6. Отчёты

### 6.1 Дашборд

**Главная страница** показывает:
- Продажи сегодня / вчера / за месяц
- Валовая выручка и прибыль
- Стоимость запасов
- Товары с низким остатком
- Количество клиентов и поставщиков
- Итоги закупок

### 6.2 Отчёт по продажам

**Reports** → **Sales Report**
- Выручка, прибыль, маржа, средний чек
- Разбивка по способам оплаты
- Фильтр по дате, кассиру, клиенту
- Пагинация

### 6.3 Отчёт по прибыли

**Reports** → **Profit Report**
- Выручка, себестоимость, прибыль, маржа
- Разбивка по дням / неделям / месяцам

### 6.4 Топ товаров

**Reports** → **Top Products**
- Самые продаваемые товары по выручке

### 6.5 Остатки

**Reports** → **Low Stock**
- Товары с низким остатком (≤5 ед.)
- Товары с нулевым остатком

### 6.6 Оценка запасов

**Reports** → **Inventory Value**
- Количество × средняя себестоимость по каждому товару

## 7. Клиенты

### 7.1 Создание клиента

1. **CRM** → **Customers** → **+ Add Customer**
2. Заполните:
   - Имя / Компания
   - Телефон
   - Email
   - Группа (VIP, Оптовик и т.д.)
3. Нажмите **Save**

### 7.2 Поиск клиента

- Поиск по имени, телефону, email
- Фильтр по группе

---

## 8. Бухгалтерия

### 8.1 Создание проводки

1. **Finance** → **Journal Entries** → **+ New Entry**
2. Выберите финансовый период
3. Добавьте строки (Дт / Кт)
4. Проверьте: дебет = кредит
5. Нажмите **Save as Draft**
6. Нажмите **Post** — проводка становится immutable

### 8.2 Просмотр GL

1. **Finance** → **Ledger**
2. Выберите счёт
3. Настройте даты, страницу
4. Просмотр с running balance

### 8.3 Оборотно-сальдовая ведомость

**Finance** → **Trial Balance**
- Сальдо по всем счетам на выбранную дату
- Фильтр по типу счёта

---

## 9. Закрытие рабочего дня

1. Закройте кассовую смену (см. 5.2)
2. Проверьте отчёты за день
3. Убедитесь, что нет расхождений
4. Сделайте backup (см. Deployment Guide)

## 10. Часто задаваемые вопросы

### Как создать нового пользователя?
Администратор: **Users** → **+ Add User**

### Как назначить роль?
Администратор: **RBAC** → **Roles** → **Assign**

### Где посмотреть историю операций?
Каждое действие (создание, изменение, удаление, утверждение) логируется. Audit log доступен для каждой сущности.

### Что делать, если товар закончился?
1. Проверьте остатки в **Reports** → **Low Stock**
2. Создайте Purchase Order
3. Примите товар через Goods Receipt

### Как вернуть деньги покупателю?
Через **Sales** → **Find Sale** → **Refund**.
Товар вернётся на склад автоматически.

### Почему не могу удалить продажу?
Можно удалить только DRAFT продажу. Завершённые продажи — **Refund**, не удаление.
