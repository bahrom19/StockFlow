# Stage E — KPI Strip innerText Regression Fix

**Date:** 2026-08-09
**Commit base:** `e13c054` (Stage E — Revenue + Monthly Goal)
**Scope:** presentation-layer semantics fix only. No backend, API, Prisma,
business-logic, or accounting changes.

## Problem

After Stage E, E2E Auth tests 3/4/5 failed against the committed `e13c054`
build: `"Today's Revenue"` was visually present on the Dashboard but missing
from `document.body.innerText`, which the E2E suite polls.

## Root cause (browser-level evidence)

Flutter Web serializes the semantics tree to DOM. For a semantics **group**
that contains **no interactive descendants**, the merged label text is emitted
as plain `textContent` → visible to `innerText`. When the group contains an
**interactive element** (the new pencil `IconButton` in `RevenueGoalCard`),
Flutter Web promotes the group to `role="group"` and hoists the entire merged
text into `aria-label` (invisible to `innerText`), keeping only the button's
own label as `textContent`.

- **BEFORE (`c4e8fa2`, all-`KpiCard` strip):** `role=""` nodes, text in
  `textContent` → all 5 KPI labels present in `innerText`.
- **AFTER (`e13c054`):** one `role="group"`, text in `aria-label`, only
  `"Set monthly goal"` in `textContent` → all 5 labels absent from `innerText`.

This also degraded screen-reader output (text only announced as a group label).

## Fix (validated at browser level)

Give **every** KPI card in the strip a **label-less `Semantics(container: true)`
boundary**, and restructure `RevenueGoalCard` so that:

1. All non-interactive text is folded into a **single merged semantics leaf**
   (`children=0`, rendered as `textContent` — identical to the pre-Stage-E
   `KpiCard` leaf);
2. The pencil `IconButton` is a **separate sibling** node of that leaf
   (kept interactive and accessible, never merged into the text).

### Changed files (production)

- `mobile/lib/features/dashboard/presentation/widgets/kpi_card.dart`
  — root wrapped in `Semantics(container: true)`.
- `mobile/lib/features/dashboard/presentation/widgets/revenue_goal_card.dart`
  — content restructured into
  `Semantics(container: true) > Stack[ MergeSemantics(text leaf), Positioned(pencil) ]`.
  The pencil is moved to the card's bottom-right; the goal line reserves a
  34px right lane so text never runs underneath the button. Visual layout,
  hover/press, dialog, and monthly-goal behavior are unchanged.

### Regression guard (E2E)

- `e2e/tests/auth.spec.ts` test 3 now asserts **all five** KPI labels
  (`Today's Revenue`, `Today's Sales`, `Gross Profit`, `Inventory Value`,
  `Customers`) through `document.body.innerText`.
- New test 11: pencil opens the Monthly Goal dialog, `Goal amount` typed,
  Save shows `of $2.0M`; a full reload re-shows the persisted goal
  (SharedPreferences), proving save/reload persistence and that the pencil
  remains interactive after the restructure.
